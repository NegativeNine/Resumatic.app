# Fonts

The two typefaces the web app uses. `../styles/fonts.css` loads them.

| File | Typeface | Axes | Source |
| --- | --- | --- | --- |
| `schibsted-grotesk-latin-wght-normal.woff2` | Schibsted Grotesk | weight 400–900 | `@fontsource-variable/schibsted-grotesk` 5.3.0 |
| `schibsted-grotesk-latin-ext-wght-normal.woff2` | Schibsted Grotesk | weight 400–900 | `@fontsource-variable/schibsted-grotesk` 5.3.0 |
| `newsreader-latin-wght-italic.woff2` | Newsreader italic | weight 200–800 | `@fontsource-variable/newsreader` 5.3.0 |
| `newsreader-latin-ext-wght-italic.woff2` | Newsreader italic | weight 200–800 | `@fontsource-variable/newsreader` 5.3.0 |

Both typefaces are licensed under the SIL Open Font License 1.1. The licence texts are `OFL-SchibstedGrotesk.txt` and `OFL-Newsreader.txt`, and they must stay next to the font files.

Newsreader is the weight-only file (64.5 kB). The design system also has a file with the optical-size axis (146.9 kB), which the app doesn't need at quote sizes.
