# Fonts

The one typeface the web app uses. `../styles/fonts.css` loads it.

| File | Typeface | Axes | Source |
| --- | --- | --- | --- |
| `atkinson-hyperlegible-next-latin-wght-normal.woff2` | Atkinson Hyperlegible Next | weight 200–800 | `@fontsource-variable/atkinson-hyperlegible-next` 5.3.0 |
| `atkinson-hyperlegible-next-latin-ext-wght-normal.woff2` | Atkinson Hyperlegible Next | weight 200–800 | `@fontsource-variable/atkinson-hyperlegible-next` 5.3.0 |

Licensed under the SIL Open Font License 1.1. The licence text is `OFL-AtkinsonHyperlegibleNext.txt`, and it must stay next to the font files. The latin file is byte-identical to the design system's.

There is no italic file: quotes are upright, in the same face. The resume sheet prints in `--font-paper` (Helvetica Neue, Helvetica, Arial), as the PDF does, and loads no font file.
